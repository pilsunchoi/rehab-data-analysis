# OAI 변수 목록 — 무릎 기능 궤적과 인공관절 치환술

작성일: 2026-11-18
대상: Osteoarthritis Initiative(OAI) 공개 임상 데이터 가운데 첫 분석(`analysis/01-function-trajectory-tkr.qmd`)이 쓰는 파일과 변수
목적: 받을 파일, 변수 이름의 꼴, 분석 단위와 사건 정의를 한곳에 정한다. 이름이 확인되지 않은 변수는 미확인으로 적고, 분석 문서가 실제 데이터의 열 이름과 대조해 확정한다.

---

## 0. 목적과 범위

첫 질문은 하나다. 무릎 기능 점수(WOMAC 기능)의 개인별 궤적이 인공관절 치환술(TKR)의 위험을 얼마나 예측하는가. 분석 단위는 무릎이고, 한 사람의 두 무릎은 군집으로 다룬다.

이 문서는 그 질문에 필요한 변수만 담는다. 영상 정량값, 가속도계, 혈액 바이오마커는 다음 단계에서 덧붙인다.

판단이 갈리면 다음 순서를 따른다. 첫째, 변수 이름은 이 문서가 아니라 OAI 데이터 사전이 정한다. 둘째, 사건 정의는 판정된(adjudicated) 치환술만 사건으로 센다.

## 2. 파일의 꼴

다음은 OAI 데이터를 쓰는 공개 코드 저장소에서 확인한 것이다(2026-11-18). OAI 데이터 사전으로 직접 확인하지는 않았다.

| 항목 | 내용 |
|---|---|
| 형식 | 세로막대(`\|`)로 구분한 ASCII 텍스트. SAS 판도 있다 |
| 열 이름 | 대문자. 방문 번호 접두어가 붙는다(`V00`, `V01`, …). 등록 시점 변수는 `P01`, `P02` |
| 범주 값 | `1: Male`, `2: Grade 2`처럼 숫자와 설명이 함께 적힌다. 앞의 숫자만 쓴다 |
| 결측 | 점으로 시작하는 부호(`.: Missing Form…` 꼴). 모두 결측으로 읽는다 |
| 좌우 무릎 | 임상 파일은 넓은 꼴이다. 오른쪽·왼쪽 열이 따로 있고 끝 글자 `R`, `L`로 구분한다 |
| 영상 판독 | 긴 꼴이다. `SIDE` 열이 `1: Right`, `2: Left`로 무릎을 가른다. 판독 사업(`READPRJ`)이 여럿이면 한 무릎에 여러 줄이 있다 |

읽는 함수는 `R/oai.R`의 `read_oai_txt`다. 위 규칙을 모두 처리한다.

## 3. 방문 일정

방문 번호와 개월의 대응은 받은 데이터로 확인했다. 18·30개월 방문은 일부 대상자만 받았다.

| 방문 | 개월 | 확인 |
|---|---|---|
| V00 | 0 | 확인 |
| V01 | 12 | 확인 |
| V02 | 18 | 확인, 일부 대상자 |
| V03 | 24 | 확인 |
| V04 | 30 | 확인, 일부 대상자 |
| V05 | 36 | 확인 |
| V06 | 48 | 확인 |
| V07 | 60 | 확인 |
| V08 | 72 | 확인 |
| V09 | 84 | 확인 |
| V10 | 96 | 확인 |
| V11 | 108 | 확인 |
| V12 | 120 | 확인 |
| V13 | 168 | 확인, 부호 이름은 Year 14 |
| V14 | 192 | 확인, 부호 이름은 Year 16 |

개월은 `Outcomes99.txt`의 마지막 접촉 방문 변수 `V99RNTCNT`의 부호 이름(예: `11: 108-month`)으로 확인했다(2026-11-20). V13과 V14는 12개월 간격이 아니다. 이 표는 `R/oai.R`의 `VISIT_MONTHS`에 같은 값으로 들어 있으므로 고칠 때는 두 곳을 함께 고친다.

## 4. 변수 목록

변수 이름의 꼴에서 `{v}`는 방문 번호 두 자리, `{s}`는 무릎(`R` 또는 `L`)이다. 분석 문서는 이 꼴을 정규식으로 바꿔 실제 열 이름과 대조하고, 맞는 열이 없으면 비슷한 열을 보여 준다. 꼴은 `R/oai.R`의 `VARIABLES`에 있다.

### 4.1 사람 단위

| 개념 | 파일 | 이름의 꼴 | 값 | 확인 |
|---|---|---|---|---|
| 대상자 번호 | 모든 파일 | `ID` | 정수 | 확인 |
| 성별 | `Enrollees.txt` | `P02SEX` | 1 남, 2 여 | 확인 |
| 기준 나이 | `AllClinical00.txt` | `V00AGE` | 세 | 확인 |
| 기준 BMI | `AllClinical00.txt` | `P01BMI` | kg/m² | 확인 |
| 하위 코호트 | `Enrollees.txt` | `V00COHORT` | 진행·발생·비노출 | 미확인 |

### 4.2 무릎 단위, 기준 시점

| 개념 | 파일 | 이름의 꼴 | 값 | 확인 |
|---|---|---|---|---|
| Kellgren-Lawrence 등급 | `kXR_SQ_BU00.txt` | `V00XRKL` | 0\~4 | 확인 |
| 무릎 | `kXR_SQ_BU00.txt` | `SIDE` | 1 오른쪽, 2 왼쪽 | 확인 |
| 판독 사업 | `kXR_SQ_BU00.txt` | `READPRJ` | 15, 37, 43. 15가 거의 모든 무릎을 판독했으므로 15를 먼저 쓴다 | 확인 |

파일 이름의 대소문자는 판마다 다르다. 2026-11-20에 받은 판은 `KXR_SQ_BU00.txt`, `OUTCOMES99.txt`, `ALLCLINICAL13.txt`처럼 대문자가 섞여 있다. 읽는 함수는 대소문자를 가리지 않는다.

### 4.3 무릎 단위, 방문마다

| 개념 | 파일 | 이름의 꼴 | 범위 | 확인 |
|---|---|---|---|---|
| WOMAC 기능(일상생활 곤란) | `AllClinical{v}.txt` | `V{v}WOMADL{s}` | 0\~68, 클수록 나쁨 | 확인(V00\~V14) |
| WOMAC 통증 | `AllClinical{v}.txt` | `V{v}WOMKP{s}` | 0\~20 | 확인 |
| WOMAC 뻣뻣함 | `AllClinical{v}.txt` | `V{v}WOMSTF{s}` | 0\~8 | V00 확인 |

### 4.4 사람 단위, 방문마다 (2026-11-21 실측)

| 개념 | 파일 | 이름의 꼴 | 범위 | 확인 |
|---|---|---|---|---|
| 신체활동(PASE 총점) | `AllClinical{v}.txt` | `V{v}PASE` | 0 이상, 클수록 활동적. 기준 방문의 평균 161, 최댓값 531 | 확인(V00, V01, V03, V05, V06, V08, V10, V13) |
| 방문 시점의 BMI | `AllClinical{v}.txt` | `V{v}BMI` | kg/m² | 확인(V01\~V13). 기준 방문은 `P01BMI`. V13은 결측이 81% |

PASE는 0, 12, 24, 36, 48, 72, 96, 168개월 방문에만 있다. 항목별 응답(`V{v}PASE1`\~`V{v}PASE6`, `V{v}HOUACT1`\~`6`)도 같은 파일에 있으나 쓰지 않았다. 가속도계 자료는 일부 대상자의 48개월과 72개월 방문에 있다고 알려져 있으나, 2026-11-20에 받은 파일에는 들어 있지 않다.

### 4.5 사건

| 개념 | 파일 | 이름의 꼴 | 값 | 확인 |
|---|---|---|---|---|
| 치환술 판정 | `Outcomes99.txt` | `V99E{s}KRPCF` | 3 판정 확정, 1 자기 보고, 0 판정했으나 불확인 | 확인 |
| 등록부터 치환술까지 일수 | `Outcomes99.txt` | `V99E{s}KDAYS` | 일 | 확인 |

사건 변수는 2026-11-20에 받은 데이터로 확인했다. 사건은 부호 3(판정 확정)만 센다. 자기 보고(1)와 판정에서 확인되지 않은 것(0)은 사건이 아니다. 부호는 `R/oai.R`의 `TKR_CONFIRMED`에 있다.

## 5. 분석 단위와 정의

| 항목 | 정의 |
|---|---|
| 분석 단위 | 무릎. 사람 번호로 군집 강건 표준오차를 쓴다 |
| 제외 | 기준 시점 전에 치환술을 받은 무릎, 기준 KL 등급이 없는 무릎, 기준 WOMAC 기능이 없는 무릎 |
| 시간 원점 | 등록(V00) |
| 사건 | 판정된 치환술. 시각은 등록부터의 일수를 30.4375로 나눈 개월 |
| 중도절단 | 사건이 없으면 그 무릎의 WOMAC 기능이 마지막으로 관측된 방문의 개월 |
| 사건 뒤 측정 | 쓰지 않는다. 치환술 뒤의 점수는 다른 무릎을 재는 셈이다 |
| 시간에 따라 바뀌는 공변량 | 직전 방문의 WOMAC 기능을 다음 방문까지 유지한다 |

사망은 치환술의 경쟁 위험이지만 첫 분석에서는 중도절단으로 다룬다. 이 선택은 6장에서 다시 본다.

---

## 6. 미확인 사항과 다음 단계

1. 사건 변수의 이름과 부호(4.5), 방문과 개월의 대응(3장), 판독 사업의 우선순위(4.2)는 2026-11-20에 확인했다.
2. 중도절단 시각. 지금은 WOMAC 기능을 마지막으로 관측한 방문이지만, 사건은 그 뒤에도 판정된다. 마지막 접촉 방문(`V99RNTCNT`)을 쓸지 정한다.
3. 방문 개월은 명목 값이다. 실제 방문 일자 변수를 쓸지 정한다.
4. 사망을 경쟁 위험으로 다룰지. 사망 일자 변수가 `Outcomes99.txt`에 있는지부터 본다.
5. WOMAC 기능의 바닥 효과. 0에 몰린 질량을 다루는 모형(절단·검열 분포, 두 부분 모형)을 결합모형의 종단 쪽에 넣는다.
